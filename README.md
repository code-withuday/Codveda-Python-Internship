## 2. Number Guessing Game
A fun command-line game where:

- The user tries to guess it

- Add tasks

A real-time weather application using API integration.

- Python

A simple Caesar Cipher based encryption project.

- ASCII values
- ord() function
- chr() function
- Loops & String Manipulation
